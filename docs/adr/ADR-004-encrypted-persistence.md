# ADR-004: Зашифрованное локальное хранилище на базе Drift и SQLCipher

## Статус
**Принято (Accepted)**

## Контекст
AndroMac кэширует на диске macOS и Android определенный объем пользовательских данных:
- Историю синхронизированных SMS-диалогов и сообщений для быстрого поиска и чтения офлайн.
- Журнал поступивших уведомлений (по умолчанию 7 дней).
- Историю буфера обмена (ограниченный пул из 20 последних элементов).
- Реестр сопряженных устройств и отпечатки доверенных сертификатов пиров (`CertificatePinStore`).

В случае утери, кражи устройства или создания резервной копии (Time Machine, Android cloud/local backup) открытое хранение базы данных SQLite ставит под угрозу персональную информацию пользователя (PII, токены, личную переписку).

## Решение

1. **Технологический стек хранилища:**
   - В качестве ORM и уровня доступа к данным выбран **Drift** (типобезопасные запросы, реактивные потоки `watch()`, генерация миграций).
   - В качестве движка базы данных выбран **SQLCipher** (полнодисковое шифрование страниц базы данных алгоритмом AES-256 в режиме CBC с HMAC-SHA512 аутентификацией каждой страницы).

2. **Управление ключами шифрования базы данных:**
   - 256-битный ключ базы данных генерируется при первом запуске с помощью криптографически стойкого генератора случайных чисел (CSPRNG).
   - Ключ никогда не сохраняется в открытом виде на диске или в коде приложения.
   - **macOS:** Ключ помещается в `macOS Keychain Services` с атрибутом доступа `kSecAttrAccessibleAfterFirstUnlock`.
   - **Android:** Ключ защищается через `AndroidKeyStore` с привязкой к аппаратному модулю безопасности (Hardware-backed Keystore / StrongBox Keymaster) через `EncryptedSharedPreferences`.

3. **Политики хранения и очистки (Data Retention):**
   - **Буфер обмена:** Ограничен 20 последними элементами. При заполнении вытесняется по алгоритму FIFO. Элементы с флагом `isPinned == true` защищены от автоматического удаления.
   - **Уведомления:** Автоматическая очистка записей старше 7 дней фоновой задачей.
   - **Полное удаление (Wipe):** При отмене сопряжения устройства на любой стороне связанные кэшированные данные и отпечатки сертификата немедленно и безвозвратно удаляются.

## Последствия

### Положительные:
- Полная защита данных в покое (Data-at-Rest) даже при извлечении файлов приложения с накопителя.
- Высокая производительность и типобезопасность запросов благодаря Drift.
- Соответствие строгим мировым стандартам конфиденциальности (GDPR, NIST).

### Отрицательные:
- Небольшой оверхед на шифрование страниц при интенсивных дисковых операциях (практически незаметен на современных SSD и UFS).
- Необходимость поставки нативных бинарных библиотек SQLCipher (`sqlite3.so` / `sqlite3.dylib`) для целевых платформ.
