# AndroMac — Руководство по устранению неполадок фоновой работы (OEM Background Troubleshooting Guide)

## 1. Введение и суть проблемы

Приложение AndroMac требует поддержания непрерывного сетевого соединения (mTLS WebSocket) и наблюдения за системными событиями (SMS, входящие уведомления, буфер обмена) в режиме 24/7.

Однако стандартные механизмы Android и специализированные оболочки вендоров (OEM) содержат агрессивные модули энергосбережения и оптимизации памяти, которые могут принудительно «усыплять» или завершать фоновые процессы.

Данный документ описывает пошаговые инструкции для пользователей и алгоритмы автодиагностики приложения в соответствии с рекомендациями `dontkillmyapp.com` и спецификациями Android 10–15.

---

## 2. Разрешение «Ограниченные настройки» (Android 13+ Restricted Settings)

Начиная с Android 13, при установке APK-файла напрямую (sideloading вне Google Play) система по умолчанию блокирует доступ к специальным возможностям и чтению уведомлений, помечая их как **«Ограниченные настройки»** (Restricted settings).

### Пошаговая инструкция для пользователя:
1. Откройте системные **Настройки** телефона.
2. Перейдите в раздел **«Приложения»** → **«Все приложения»** → найдите и выберите **AndroMac**.
3. В правом верхнем углу экрана нажмите на значок меню с тремя точками (`⋮`).
4. Выберите пункт **«Разрешить ограниченные настройки»** (Allow restricted settings).
5. Подтвердите действие с помощью отпечатка пальца или PIN-кода устройства.
6. Вернитесь в AndroMac и повторно включите **«Доступ к уведомлениям»**.

## 3. Специфика оболочек вендоров (OEM Guidelines)

### 3.1 Xiaomi / Redmi / POCO (MIUI / HyperOS)

Оболочка Xiaomi имеет рейтинг агрессивности 5/5 по шкале `dontkillmyapp.com`.

**Необходимые настройки:**
1. **Автозапуск (Autostart):**
   - Настройки → Приложения → Разрешения → Автозапуск в фоновом режиме → Включить для **AndroMac**.
   - Дополнительно разрешить «Автозапуск другими приложениями».
2. **Контроль активности батареи:**
   - Настройки → Приложения → Все приложения → AndroMac → **Контроль активности** → Установить в положение **«Нет ограничений»** (No restrictions).
3. **Закрепление в меню недавних задач (Lock in Recents):**
   - Откройте меню недавних приложений (свайп вверх и удержание).
   - Зажмите карточку AndroMac и нажмите на значок **«Замок»** (🔒).
4. **Оптимизация MIUI (MIUI Optimization):**
   - Если при перезагрузке сбрасываются разрешения: Настройки для разработчиков → выключить «Оптимизация MIUI / Включить системную оптимизацию».

---

### 3.2 Samsung Galaxy (One UI)

**Необходимые настройки:**
1. **Исключение из спящих приложений:**
   - Настройки → Обслуживание устройства (Батарея) → Ограничения в фоновом режиме.
   - Убедитесь, что AndroMac **НЕ** находится в списках «Приложения в режиме сна» и «Приложения в глубоком сне».
   - Добавьте AndroMac в список **«Неспящие приложения»** (Never sleeping apps).
2. **Оптимизация расхода батареи:**
   - Настройки → Приложения → AndroMac → Батарея → Выберите пункт **«Не ограничено»** (Unrestricted).
3. **Автоматическая оптимизация устройства:**
   - Настройки → Обслуживание устройства → Автоматическая оптимизация → Отключите «Перезапуск при необходимости» либо убедитесь, что AndroMac восстанавливается через `BootReceiver`.

---

### 3.3 Huawei / Honor (EMUI / Magic UI)

**Необходимые настройки:**
1. **Управление запуском (App Launch):**
   - Настройки → Батарея → Запуск приложений.
   - Найдите AndroMac и переключите тумблер с «Автоматическое управление» на **«Ручное управление»**.
   - Активируйте все 3 пункта:
     - [x] Автозапуск
     - [x] Косвенный запуск
     - [x] Работа в фоновом режиме
2. **Оптимизация работы батареи:**
   - Настройки → Приложения → Приложения → значок настроек/меню → Специальный доступ → Оптимизация работы батареи → Выберите «Все приложения» → AndroMac → **«Запретить»** (Не оптимизировать).

---

### 3.4 OnePlus (OxygenOS)

**Необходимые настройки:**
1. **Оптимизация батареи:**
   - Настройки → Батарея → Оптимизация батареи → AndroMac → **«Не оптимизировать»** (Don't optimize).
2. **Расширенная оптимизация (Sleep Standby Optimization):**
   - Настройки → Батарея → Расширенные настройки → Отключите «Оптимизация режима ожидания» (Sleep standby optimization).
3. **Закрепление в недавних приложениях:**
   - Откройте меню задач → значок меню карточки AndroMac → **«Блокировка»** (Lock).

---

### 3.5 Realme / OPPO (ColorOS) & Vivo (FuntouchOS / OriginOS)

**Необходимые настройки:**
1. **Разрешение на работу в фоне:**
   - Настройки → Управление приложениями → AndroMac → Расход заряда батареи → Включить **«Разрешить работу в фоновом режиме»** и **«Разрешить автозапуск»**.
2. **Управление фоновым питанием (High Background Power Consumption):**
   - Настройки → Батарея → Другие настройки батареи → Разрешить высокое энергопотребление в фоновом режиме для AndroMac.

## 4. Проблемы с сетевым подключением в локальной сети (LAN & Wi-Fi)

Если устройства не находят друг друга по mDNS или не могут установить TCP-соединение:

| Симптом / Причина | Механизм возникновения | Решение |
| :--- | :--- | :--- |
| **Изоляция клиентов Wi-Fi (AP Isolation)** | Роутер запрещает прямое взаимодействие между устройствами в беспроводной сети (часто включено в гостевых сетях, отелях, офисах). | Отключить «AP Isolation» / «Client Isolation» в веб-интерфейсе роутера, либо использовать режим USB-модема / мобильной точки доступа. |
| **Активный VPN на Mac или телефоне** | VPN перехватывает маршрутизацию локального трафика (`192.168.x.x`) и направляет его в туннель. | Включить опцию «Local Network Sharing» / «Bypass VPN for local traffic» в настройках VPN-клиента (Tailscale, WireGuard, ShadowSocks). |
| **Разрешение «Локальная сеть» на macOS** | Начиная с macOS 15 (Sequoia), требуется явное системное согласие на поиск устройств в LAN. | Системные настройки → Конфиденциальность и безопасность → Локальная сеть → Включить для AndroMac. |
| **Спящий режим Wi-Fi на Android** | Некоторые прошивки отключают Wi-Fi модуль при выключенном экране. | Включить в настройках разработчика пункт «Всегда держать Wi-Fi включенным» (Keep Wi-Fi on during sleep). |
| **Эмулятор Android (AVD)** | Эмулятор изолирован во внутренней виртуальной подсети NAT. | Использовать обратный хост-адрес `10.0.2.2:<порт>` для подключения к серверу Mac. |

## 5. Чек-лист экспресс-самодиагностики (In-App Checklist)

В мобильном приложении на вкладке **«Диагностика»** реализована автоматическая проверка следующих условий:
1. `[x]` Служба **Foreground Service** активна и удерживает постоянное уведомление.
2. `[x]` Разрешение **NotificationListenerService** предоставлено и активно.
3. `[x]` Исключение из **Doze Mode** получено (`isIgnoringBatteryOptimizations == true`).
4. `[x]` Локальная сеть доступна и получен действительный IPv4-адрес.
5. `[x]` Порт mTLS сервера (8765) свободен и слушает входящие соединения.
6. `[x]` Разрешения SMS предоставлены (для сборки `direct`).
